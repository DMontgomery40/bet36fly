# Film source notes

Checked September 14, 2026. The film describes public resources and local bet36fly evidence as they stood at production. Revision four reuses existing scientific editorial stills previously generated with explicitly selected OpenAI API model `gpt-image-2.5-sunburst`. No new images are generated and no bespoke animations are used. Generated images are conceptual illustrations, including microscopic and neural views. They are not captured experiments or empirical activity recordings. The backtest image uses the frozen result's values. Prompts and corrections are recorded under `sources/`; [the model documentation](https://developers.openai.com/api/docs/models/gpt-image-2.5-sunburst) was checked before selecting the API identifier.
