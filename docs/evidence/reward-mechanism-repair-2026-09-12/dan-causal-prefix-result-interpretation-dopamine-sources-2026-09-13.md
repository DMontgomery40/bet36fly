# Independent interpretation of the completed DAN causal-prefix audit

September 13, 2026. This review read all 64 complete contrast JSON records,
summary and terminal receipts from `dan-causal-prefix-b3bbc7ad5a3c1040de18`.
It did not reopen waveform arrays, execute the driver, replay a learning rule,
run a circuit, fit a parameter or search for another source.

The recorded electrical teaching distinction is present in every comparison.
At step 1550 (310 ms), untaught DAN counts are `[0,0]`, while home teaching
has `[2,0]` and away teaching has `[0,22]`. Because the verified record is
binary per cell per step, saturation also determines cell membership at that
single event: every selected target DAN fired, versus none in untaught.
This does not reconstruct complete taught per-cell histories. The existing
`per_cell_taught_history_established=false` flag remains appropriate.

The current-code causal argument guarantees equal individual KC event histories
through step 1550 inclusive. All 64 records also report no total-KC or grouped
KC-state difference during the entire 2000-step trial. Those aggregate
observations cannot extend the individual-KC guarantee after step 1550.
All eight descriptive groups contain eight cases. The whole-trial **net**
actual DAN count difference is 8 for 31 home cases and 7 for one home case;
it is 88 for all 32 away cases. These are neither dopamine concentrations
nor a diagnosis of which requested pulse produced, suppressed or displaced
which later spike.

Thus the narrow explanation that these matched current-code contrasts lack
an actual pooled electrical teaching distinction is ruled out. This is not
evidence that chemical release, local exposure, receptor occupancy or
intracellular priming represents that distinction correctly. It does not
select a learning law or show that any candidate passes the untaught guard,
qualification, conditioning, retention or reversal. The old identical-D-only
attribution is still insufficient because the rule also depends on KC input
and gain feedback. All accepted masks, gains, clocks and criteria remain fixed.

The failed first attempt is part of the record: v1
`dan-causal-prefix-cb7eb73ca0c41bd37e4b` exited 1 after 0.530719 seconds,
with zero contrasts, because its reader expected int32 main selectors where
the producer stored int64. The separately identified v2 completed once in
4.067663 parent seconds, exit 0, reaped, under the 120-second cap. This is
one reader false start followed by one completed analysis, not two neural
