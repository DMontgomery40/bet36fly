## Smallest implementable interface

Separate **observing/evolving a physical signal**, **computing a plasticity drive**, and **authorizing a gain write**. Do not use the existing variable named `learning` as the new state's clock switch: it means only `t>=onset_steps`, while plasticity-off is represented separately by eta0.

A standalone component should first accept an immutable kinetic specification, an explicit initial state and a typed event/level input contract. It should expose `advance(state, input, interval)` returning the next float64 state, independently observable branch outputs and any interval integrals; it should expose a separately defined no-input continuation. No implicit source-clock conversion, state reset, teaching label, parameter default borrowed from100/500ms, or gain update belongs in a generic state transition. Synthetic source-protocol reproduction can meaningfully test this before a native port, without claiming that experimental population stimulation is calibrated individual-spike input.

An eventual native adapter belongs immediately after actual spike selection (`reward_lif.cpp:210–216`), outside the gain-onset conditional. Common KC state can use `[4064,S_K]`; compartment-specific intracellular state should use a declared map of unique `(KC, channel)` locations to `[locations,S_local]`, with an edge-to-location index. This preserves a shared soma while avoiding cross-channel state mixing and duplicate advancement for multiple outgoing edges. It is a spatial approximation, not newly observed synaptic geometry. Preserve all original body IDs, KC classes and eligibility flags; masked edges need not make their KCs chemically silent.

Every step must have an explicit ordering: recover/evolve to the event time, apply the declared simultaneous-event convention, compute branch output over the next0.2ms interval, and only then publish an allowed gain change. If the source is intrinsically discrete, retain its own clock with rational/integer boundary accounting; do not reinterpret its recurrence at5000Hz. Update chemistry from trial time0 even when writes are disabled, with a declared initial state. Before100ms, suppress gain writes and preserve cold *old bridge* filters. Do not accumulate a deferred pre-onset gain debt and apply it at step500.

That separation is not the rejected onset-only hypothesis. It adds a independently specified state with its own observable dynamics, while retaining the old signal admission boundary wherever the old bridge remains in use. The rejected onset, L/C and DARELA constructions remain rejected. A new mode cannot silently rename their states or reuse their verdicts.

## Tail, duration and memory are different decisions

An event-amplitude transform that emits nothing without a new event can reuse the existing bridge's analytic tail: no new input enters that linear system. A joint chemical state that continues generating plasticity drive between events cannot. It needs the full coupled continuation, an integrability/resting-state proof, separate signed branch areas, and a frozen publication/bound-observation policy. `RateBridge::update` relies on cancellation specific to its old equation; changing a factor inside it invalidates the old exact formula unless independently rederived.

Do not equate a chemical quiet limit with erasing memory. A model may retain latent modification while an expressed state relaxes toward it. Such a limit must preserve that distinction. Conversely, integrating infinite future drive before every reset imposes a trial-completion convention; it cannot stand for a finite intertrial gap or a delayed behavioral probe. Record electrical-end state and gains separately from completed mathematical-tail state and gains.

The present400/800ms calls can observe the early response of a slower mechanism; slowness alone does not prove no early effect. They cannot reproduce omitted500ms stimulation, multi-second separated inputs, minute-scale induction, or chemical carryover between calls. A continuous seconds/minutes source assay needs a separate source-protocol component. A later circuit protocol requiring chemical memory across calls would need an explicit resumable state checkpoint (including electrical/RNG/delay state if electrical continuity is claimed), elapsed gap, clone/restore semantics and new qualification—not an undocumented extra field on the current gain-only checkpoint. No timing change is selected here.

## New primary constraint

Yamada et al.2024 studied γ and α/β inputs to MBON-γ1pedc. Their focal dopamine/forskolin experiments distinguish cAMP elevation from presynaptic LTD: KC activity is also required downstream. Imaging is separate from EPSC/PPR measurement. Induction pairs1ms KC photostimuli at2Hz with1min focal delivery; cGMP-associated presynaptic potentiation required repeated pairing and developed slowly. α/β depression recovered around10min, while γ depression persisted at least30min. High-dose forskolin could depress EPSCs without the paired PPR change; absence of PPR change does not identify the site conclusively. These results motivate separate chemical observation and downstream plasticity output, not fitted kinetic constants or a universal compartment law. They do not justify gamma-filtering home. [Full primary Methods, Results and relevant Discussion, checked2026-09-13](https://physoc.onlinelibrary.wiley.com/doi/full/10.1113/JP285745).
