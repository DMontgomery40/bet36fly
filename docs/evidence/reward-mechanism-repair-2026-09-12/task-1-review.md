Rejected events still advance the pulse cursor or leave the processed recurrent queue; neither is stored for release. Checking the target inside the edge loop preserves other postsynaptic targets. Signed weights are untouched. Sensory neurons remain governed by their existing zero-refractory assignment. The threshold and reset order is unchanged, so duplicated same-step pulses yield at most one threshold event. Learning continues to use the resulting `spiked` vector, not requested pulse metadata.

The implementation retains the exact local boundary `step >= ready`, with 11 steps for 2.2 ms at the sole supported dt of 0.2 ms, and the nine-step recurrent delay. The teaching guard is after integration and before threshold; the recurrent guard is before integration. There is no added rate filter, baseline manipulation, encoder/readout change or drive-gain adjustment hidden in these guards.

The widened tests in `tests/test_reward_brain.py:190` onward run beyond release and subsequent release, rather than ending at 2 ms. Teaching cases include early, middle, last-before-release, exact-release, after-release, repeated rejection, duplicated impulses and independent DAN histories. Frozen/learning and recorded/unrecorded paths are covered. Counts, sampled bins and recorded DAN signals are asserted. The gain oracle sums signed exponential contributions from independently specified **accepted spike times**, so a scheduled-but-rejected event cannot quietly enter learning.

The recurrent matrix uses both signs, several relative arrival times, an already refractory target and a simultaneously available second target.
