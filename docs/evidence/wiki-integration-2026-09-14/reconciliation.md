## Reconciled discrepancies

1. **Conditioning “never run” versus passed.** The old reward program remains gated by SCI-001. The later associative engine uses different compartments and protocols and passed conditioning-02/03. Old failures are preserved under a clearly named legacy scope rather than overwritten or generalized to every model.
2. **Three different output systems.** Frozen sensory uses Clavicle/Quasimodo; new conditioning uses MBON05/MBON01; legacy reward uses MBON11/MBON09. The old atlas's selected roles and generated tables stay unchanged; current cell pages link new exact body IDs separately.
3. **4,108 gain slots versus 3,417 eligible edges.** The constructor and saved anatomy agree: 1,999 + 2,109 selected KC→MBON slots, of which 1,839 + 1,578 are gamma-eligible. The other 691 transmit without updates. The season reports' rounded floor fractions use all slots; the stress runner masks by eligible compartment. The wiki names each denominator and the static audit records both for the checked final recovery checkpoints.
4. **Stress γ5 discrepancy.** `continual-learning.md`'s prose says 14.5% → 3.6% while its cycle-24 table and saved manifests say **21.736% → 4.373%**. The wiki uses the saved cycle-24 values and preserves the original result file untouched. Cycle-phase rest limits are separate from final post-history reversal, where backward potentiation can exceed rest. Conditioning-03 passing at ρ 0.04 is compatible with a later stress reversal seed failing.
5. **Retired-cue “−46” as a mean.** The baseline final three-seed values are −46/−45/−51, mean −47.33, not −46. The integrated page retains full vectors and avoids promoting a shorthand seed value to a mean. Increased depression supports an interference hypothesis, not clean isolated forgetting.
6. **8,543 contacts to “the fan-shaped body.”** The reproducible selector is `MBON → class=CX`. The wiki calls this the total CX path, not a fan-shaped-body-only count. LH uses a `type.startswith('LH')` proxy; descending uses exact `superclass=descending_neuron`. An initial audit draft used the nonexistent superclass `descending`, returned zero, and was corrected before publication; the final results reproduce 1,314 neurons and 7,187/22,810/4,347 CX/LH/MBON contacts.
7. **All optic sensory cells called photoreceptors.** The 6,098 count is `superclass=ol_sensory`; 6,091 are `class=visual`. The wiki records selectors instead of equating every superclass row with a measured photoreceptor subtype. Visual→KC totals and the 206 KCg-d cells were independently reproduced. Anatomical presence does not establish retinotopic stimulation or successful visual computation.
8. **Richer recordings versus new probes.** All 2,429 rows in each of the three recovery arms were inspected programmatically: each stores two counts per team, not broader downstream traces; each has 179 daily checkpoint files. A richer channel set needs separately authorized plasticity-off re-probes. Timing/cost in the memo remains a planning estimate.
9. **Temporal reservoir versus state reset.** Current neural calls reset electrical state and use uniform delays/time constants. No heterogeneous-delay reservoir or continuous season-long electrical state is already implemented. The proposed sequence needs an explicit temporal state contract.
10. **Strong claims in the brainstorming memo.** “Cannot beat the encoder,” “a negative conventional screen proves no signal,” and “this is only a running win count” are hypotheses/heuristics, not established impossibility results. Their useful experimental questions are retained with estimator/information-set limits. The original memo is preserved; the wiki's integrated interpretation is authoritative for those distinctions.
11. **Literature transfers.** Lappalainen optimized for motion and compared predictions against physiology; it did not simply fit all dynamics to recordings. Huetteroth distinguishes sweet-taste γ4 from nutrient γ5b. JLK's extra potentiation is the precedent, while inactive-KC gating and rest-bounded recovery are BET36FLY deviations. Correct title-resolved source IDs replace the initial mismatched lookup leads.
12. **2018 “held” versus launched.** Claude's later session reports the single remote attempt launched as job `6aa771a921047bf1b03862ae`; older docs still said untouched. At this integration's local check, no `*confirmation*` directory existed under `output/associative/` and no completed confirmation file existed in associative dated evidence.
