# BET36FLY model card

BET36FLY uses the actual MaleCNS v1.0 neuronal connectome from HHMI Janelia, Google Research and collaborators. Its sports behavior is an experimental engineering application, not a behavior reported or validated by those researchers. It contains no language model deciding the picks and no randomly generated substitute brain.

## What is real, and what is modeled

The neuron IDs, anatomical edges and contact counts come from the official release. The retained graph contains 166,700 annotated neurons and 25,582,938 directed neuron-pair connections, representing 124,177,617 synaptic contacts. All released edges between retained neurons remain, including 10,299,701 weight-one edges and 101 self edges. Unresolved fragments and non-neuronal objects are excluded with exact accounting in the import manifest. The older female FlyWire release is the approximately 140,000-neuron brain; the September 2026 male release includes the ventral nerve cord.

Neuron dynamics use leaky integrate-and-fire equations and numerical parameters from Shiu et al., *A Drosophila computational brain model reveals sensorimotor processing* (Nature, 2024). This is an independent C++ implementation applied to the newer male graph, not a reproduction of their validated experiments on the female FlyWire graph. It advances all retained neurons and propagates spikes along their actual outgoing edges.

Rest and reset voltage are -52 mV; threshold is -45 mV; membrane time constant 20 ms; synaptic decay 5 ms; refractory time 2.2 ms; transmission delay 1.8 ms; per-contact weight magnitude 0.275 mV. Exact subthreshold integration occurs between discrete 0.2 ms events. Each trial lasts 80 ms. The constant trial seed is 42, giving common random numbers and repeatable comparisons across games. The chosen brief stimulus probes the transient response, not real-time cognition.

Presynaptic acetylcholine is modeled as excitatory; GABA, glutamate and histamine as inhibitory. Ambiguous, missing or modulator-only predictions use +1 so their edges remain active. This coarse proxy has 3,718 uncertain-sign neurons and does not reproduce receptor-specific physiology. Some model neurons fire at high rates; numerical activity is not proof of physiological validity.

## Inputs and outputs

Sixteen pregame features describe lagged team Elo, form, win rate, games played, rest and score margin, plus sport. Training-only scaling is saved in the checkpoint. Positive and negative feature channels drive 32 evenly spaced, real ALPN neurons from the 686-neuron annotated ALPN catalog, using artificial 30–270 Hz Poisson stimulation. Other ALPNs remain in the graph without external drive. The feature-to-neuron mapping is an artificial sensory interface; the model does not read screenshots, understand team names, watch a browser, or receive outcome labels as inputs.

The prediction readout receives actual firing rates from the 97 MBONs and average activity by neuronal superclass. Externally stimulated ALPN neurons are excluded from superclass readouts, preventing a direct sensory-feature shortcut. The artificial learned readout maps spikes to home/draw/away probabilities; the draw output is disabled for MLB.

## Real training program

1. Run each historical pregame stimulus through the entire initial spiking brain and cache the resulting neural activity. The cache identity includes the graph, current synaptic weights, input matrix, neural code, seed, timestep and trial duration.
2. Train a differentiable rate surrogate to learn bounded positive multiplicative gains on the 61,210 existing Kenyon-cell→MBON synapses. Gains stay within exp(-0.3) and exp(0.3), preserve transmitter signs and cannot create new edges. This supervised surrogate is an engineering approximation, not biological dopamine learning or exact backpropagation through spikes.
3. Apply these learned gains to those actual synapses in the full 166,700-neuron spiking graph. Rerun the complete brain for every game. The surrogate is discarded for serving.
4. Fit the final sports readout on those resulting real spike counts. Select epochs using validation loss; save gains, input/output scaling and readout arrays. Every served pick runs this full trained spiking network and its final readout.

The exact learned-edge count, gain range, real spike changes, training curves and held-out metrics are generated by the run. Changed weights alone are not treated as evidence of improved prediction.

## Evaluation

Training games begin with the available EPL 2023/24 and MLB 2024 data and end before July 1, 2025. Validation covers July–December 2025. The untouched test period is January–August 2026. Features update only after a conservative result-availability delay, and all scaling is fitted using training rows alone. No current bookmaker odds, provider cumulative records, injuries, lineups or player props enter the model.

Report log loss, multiclass Brier score, accuracy and calibration by sport. Compare the trained fly with training-frequency priors, a pregame-feature logistic baseline, a frozen-connectome trained readout, shuffled readout labels on the trained wiring, and a silenced-connectome control. In the shuffled-readout control, only the final readout training labels are permuted; the synaptic gains remain trained on true training labels and epoch selection uses true validation labels. This is not a permutation control of the whole learning pipeline. Export every held-out prediction. The silencing control establishes that the wiring affects the output; it does not establish that biological topology outperforms a randomized topology. One seed and one time split are preliminary evidence only. Retrospective source corrections and unknown exact historical publication times remain limitations.

## Phase 1 boundary

Upcoming fixtures are fetched from public sources. Picks are unfilled paper proposals with model probabilities and derived fair odds, not current bookmaker prices. There is no bet365 login, account connection, balance, stake sizing or betting action. API connection and real fill/settlement workflows belong to phase 2. Fly’s desk scores forecast outcomes against public final results using the first valid pregame pick per current fixture revision, across model versions. This does not settle wagers or train the model online. Public source refresh runs every 15 minutes while the local server is running.
